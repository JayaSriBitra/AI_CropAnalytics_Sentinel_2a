# Ground-truth and Validation

**Owner:** Ajay Surya (Member 5)  
**Project:** Implementation of LLMs in Agriculture: Crop Analytics Using Sentinel-2A Satellite Data

## Purpose

This module describes how reference labels (ground truth) will be checked and how crop-segmentation outputs will be evaluated. U-Net is the primary planned segmentation model. Random Forest, SVM and Naïve Bayes may be used as comparison models if implemented by the team.

## Expected data

The validation workflow expects aligned Sentinel-2A image chips and ground-truth label masks.

- Each image chip must have a corresponding mask.
- Image and mask must cover the same geographic area and use the same grid, dimensions, CRS and transform.
- Mask pixel values must follow one agreed class-ID mapping.
- NoData/unlabelled pixels must be identified and excluded from metric calculations.
- Record the source, acquisition/reference dates, geographic coverage, label-generation method and known limitations for each reference dataset.

Do not assume that a dataset has a particular source, date range, class list or label quality until the team verifies it.

## Recommended workflow

1. Build a manifest containing `sample_id`, `image_path`, `mask_path` and `group_id`.
2. Inspect image/mask pairs and confirm spatial alignment.
3. Review mask values and class mapping with the person responsible for the labels.
4. Split by geographic group (for example, field, parcel, tile or non-overlapping region), not by randomly distributing neighbouring pixels.
5. Keep the test groups untouched until final evaluation.
6. Evaluate predictions against the corresponding reference masks.
7. Report per-class and aggregate metrics, support (number of labelled pixels), class mapping, NoData handling and limitations.

## Included utilities

### 1. Inspect GeoTIFF pairs

Install the optional dependency:

```bash
pip install rasterio numpy
```

Run:

```bash
python validation/check_masks.py --image path/to/image.tif --mask path/to/mask.tif --nodata 0
```

The script checks raster dimensions, CRS, transform, band count and mask values. Confirm whether `0` is truly the NoData value for your dataset before using that argument. If zero is a valid class, do not exclude it.

### 2. Create a reproducible split

Prepare `sample_manifest.csv` with these columns:

```csv
sample_id,image_path,mask_path,group_id
chip_001,data/images/chip_001.tif,data/masks/chip_001.tif,field_A
chip_002,data/images/chip_002.tif,data/masks/chip_002.tif,field_B
```

`group_id` should identify the independent geographic unit used to prevent leakage. All chips with the same group ID are assigned to the same split.

```bash
python validation/create_split.py --input validation/sample_manifest.csv --output validation/split_manifest.csv --seed 42
```

Default proportions are 70% train, 15% validation and 15% test, approximately by sample count while keeping groups intact. With few or highly unequal groups, the resulting proportions may differ. Inspect the output and document the final split.

### 3. Calculate segmentation metrics

`metrics.py` provides pixel accuracy, per-class precision, recall, F1-score, IoU and Dice score from integer label arrays.

```python
import numpy as np
from validation.metrics import segmentation_metrics

y_true = np.array([[0, 1], [1, 2]])
y_pred = np.array([[0, 1], [2, 2]])

results = segmentation_metrics(y_true, y_pred, class_ids=[0, 1, 2], ignore_index=None)
print(results)
```

Pass the actual class IDs used by the project. Set `ignore_index` only to the agreed unlabelled/NoData class ID. Metrics are calculated over pixels remaining after that exclusion.

## Reporting checklist

- [ ] Reference-data source and label-generation process recorded.
- [ ] Class names and integer IDs agreed and documented.
- [ ] Image/mask alignment checked.
- [ ] NoData and ambiguous-label policy documented.
- [ ] Split generated by geographic group and saved.
- [ ] Test set kept separate from model development.
- [ ] Per-class metrics and class support reported.
- [ ] Limitations and any missing reference labels disclosed.
