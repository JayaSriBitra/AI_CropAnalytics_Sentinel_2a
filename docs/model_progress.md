
# U-Net Model Development Progress

## 1. Project Title
AI Crop Analytics Using Sentinel-2A Satellite Data

## 2. Objective
To develop a U-Net-based deep learning model for segmenting land-cover regions using Sentinel-2A satellite imagery.

## 3. Model Architecture
The proposed model uses the U-Net encoder-decoder architecture with skip connections.

## 4. Model Configuration
- Input channels: 3
- Input dimensions: 256 × 256 pixels
- Output classes: 8

## 5. Work Completed
- Reviewed the U-Net architecture.
- Prepared model design documentation.
- Identified the proposed input and output configuration.
- Documented the model development requirements.

## 6. Work in Progress
- U-Net source-code implementation.
- Dataset preparation and preprocessing.
- Model training and validation.

## 7. Pending Work
- Complete model implementation.
- Train the model using prepared satellite data.
- Evaluate segmentation performance using IoU, Dice and other metrics.

## 8. Expected Outcome
