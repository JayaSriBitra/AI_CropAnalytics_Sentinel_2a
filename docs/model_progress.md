
# U-Net Model Development Progress

## 1. Project Title
AI Crop Analytics Using Sentinel-2A Satellite Data

## 2. Objective
To develop a U-Net-based segmentation model
for identifying land-cover regions from
Sentinel-2A satellite imagery.

## 3. Model Architecture
The proposed U-Net architecture includes:
- Encoder
- Bottleneck
- Decoder
- Skip Connections

## 4. Model Configuration
- Input channels: 3
- Input dimensions: 256 × 256
- Output classes: 8

## 5. Work Completed
- Reviewed the U-Net architecture.
- Prepared the model design documentation.
- Identified the proposed input and output configuration.

## 6. Pending Work
- Implement the U-Net source code.
- Prepare the training pipeline.
- Train and validate the model.
- Evaluate segmentation performance.
- Integrate model predictions with the backend.

## 7. Expected Outcome
A segmentation model capable of generating
pixel-wise land-cover masks from supported
satellite imagery.
